Applied Energistics 2 Wireless Terminals - Redux
========================================
This is a Fork of a Forge Port of the Fabric port
of [Wireless Crafting Terminal](https://www.curseforge.com/minecraft/mc-mods/wireless-crafting-terminal)
, [Wireless Pattern Terminal](https://www.curseforge.com/minecraft/mc-mods/wireless-pattern-terminal)
, [Wireless Interface Terminal](https://www.curseforge.com/minecraft/mc-mods/wireless-interface-terminal), [Wireless
Fluid Terminal](https://www.curseforge.com/minecraft/mc-mods/wireless-fluid-terminal) 
and [Wireless Terminal Library](https://www.curseforge.com/minecraft/mc-mods/ae2wtlib).

*This fork works only on Minecraft forge 1.16.5.*

It features several wireless versions of Applied Energistics 2 terminals with support for [AE2 Fluid Crafting](https://www.curseforge.com/minecraft/mc-mods/ae2-fluid-crafting), [AeInfinityBooster](https://www.curseforge.com/minecraft/mc-mods/aeinfinitybooster), [AE Additions - ExtraCells2 Fork](https://www.curseforge.com/minecraft/mc-mods/ae-additions-extra-cells-2-fork) and [curios API](https://www.curseforge.com/minecraft/mc-mods/curios).

To be exact, this fork features:
  - Wireless Crafting Terminal
  - Wireless Pattern Terminal (With seamless [AE2 Fluid Crafting](https://www.curseforge.com/minecraft/mc-mods/ae2-fluid-crafting) support)
  - Wireless Interface Terminal
  - Wireless Fluid Terminal
  - Wireless Chemical Terminal (If [Mekanism](https://www.curseforge.com/minecraft/mc-mods/mekanism) and [AE Additions - ExtraCells2 Fork](https://www.curseforge.com/minecraft/mc-mods/ae-additions-extra-cells-2-fork) are installed).
  - Wireless Universal Terminal - allows you to combine multiple wireless terminals into 1 item.
  - Support for infinite range and cross-dimensional access with the help of AeInfinityBooster (if [AeInfinityBooster](https://www.curseforge.com/minecraft/mc-mods/aeinfinitybooster) is installed). 
  - Support for curios API slots (if [curios API](https://www.curseforge.com/minecraft/mc-mods/curios) is installed).
  - Magnet card - magnets items into your inventory/ME network and you can configure the filters for it.
